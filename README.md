# Mahesh's AI Resume

A fully interactive AI-powered resume. Chat with an AI version of Mahesh in real-time, powered by Claude Sonnet or GPT-4o with RAG over a personal knowledge base.

---

## Prerequisites

Make sure you have the following installed before you start:

- **Node.js** v18 or higher — [nodejs.org](https://nodejs.org)
- **npm** v9 or higher (comes with Node.js)
- At least one AI API key:
  - **Anthropic API key** (for Claude) — [console.anthropic.com](https://console.anthropic.com)
  - **OpenAI API key** (for GPT-4o + RAG embeddings) — [platform.openai.com/api-keys](https://platform.openai.com/api-keys)

Verify your setup:
```bash
node -v   # should print v18.x.x or higher
npm -v    # should print 9.x.x or higher
```

## Quick Start

### 1. Clone the repository
```bash
git clone <your-repo-url>
cd Interactive_resume
```

### 2. Install dependencies
```bash
npm run install:all
```
This installs dependencies for the root, client, and server in one command.

### 3. Set up environment variables
```bash
cp .env.example server/.env
```
Open `server/.env` and fill in your API keys:
```
ANTHROPIC_API_KEY=your_anthropic_api_key_here
OPENAI_API_KEY=your_openai_api_key_here
PORT=5000
CLIENT_ORIGIN=http://localhost:3000
```

> **Only have one key?** That's fine. The app works with just one. The other AI model will show a friendly error message if its key is missing.

### 4. Knowledge base embeddings

> **No action needed.** The `knowledge-base/embeddings.json` file is already included in the repo — pre-generated by the project owner. You can skip straight to starting the app.

If you ever update the markdown files in `knowledge-base/` and want to regenerate embeddings (requires an OpenAI API key):
```bash
npm run ingest
```

### 5. Start the app
```bash
npm run dev
```

This starts both servers concurrently:
- React client → `http://localhost:3000`
- Express server → `http://localhost:5000`

### 6. Open in browser
```
http://localhost:3000
```

## Available Scripts

| Command | Description |
|---|---|
| `npm run install:all` | Install all dependencies (root + client + server) |
| `npm run dev` | Start both client and server in development mode |
| `npm run dev:client` | Start only the React frontend |
| `npm run dev:server` | Start only the Express backend |
| `npm run ingest` | Generate embeddings from knowledge-base markdown files |

## Health Check

Verify the server is running and configured correctly:
```
GET http://localhost:5000/api/health
```
Returns which AI services are active and how many knowledge chunks are loaded.

## Troubleshooting

**Port already in use**
```bash
# Kill the process using port 3000 or 5000
lsof -ti:3000 | xargs kill
lsof -ti:5000 | xargs kill
```

**`npm run ingest` fails**
- Make sure `OPENAI_API_KEY` is set correctly in `server/.env`
- Check you have an active OpenAI account with API access

**AI responses are generic / missing details**
- Make sure `server/.env` has at least one valid API key
- Verify the server started correctly at `http://localhost:5000/api/health`
