# Certifications & Courses: Mahesh P Jakaraddi

## Microsoft Azure Fundamentals (AZ-900)
**Issuer:** Microsoft

The AZ-900 validates foundational Azure knowledge — core services, pricing models, security, compliance, and the shared responsibility model. I earned this while working at Daimler where Azure was our primary cloud. It was the formal certification to complement the hands-on AKS, networking, and App Services work I was already doing in production.

## AWS Cloud Practitioner
**Issuer:** Amazon Web Services

The AWS Cloud Practitioner badge covers the fundamental AWS services and cloud concepts. I have hands-on AWS experience with Terraform-provisioned EC2, VPC, IAM, and S3. The certification provides the formal foundation on top of the practical work.

Together with the AZ-900, these certifications reflect my multi-cloud approach — I've worked in both Azure-heavy (primary at Daimler) and AWS environments.

## Speak English Professionally
**Issuer:** Georgia Tech / Coursera

A communication course from Georgia Tech focused on professional English in technical and business contexts. I took this intentionally — as someone who worked in India and is now building a career in the US, I wanted to sharpen my professional communication skills for interviews, cross-cultural collaboration, and technical presentations.

## Data Structures & Algorithms
**Issuer:** Udemy

A focused DSA course covering arrays, linked lists, trees, graphs, sorting, searching, and dynamic programming. I took this to sharpen my algorithmic thinking ahead of technical interviews and to complement my computer science work. DSA is foundational — even as a DevOps engineer, understanding Big-O and efficient data structures informs how I think about pipeline efficiency, data processing, and system design.
